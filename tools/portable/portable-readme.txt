HandPilot - управление компьютером жестами рук (Windows 10/11, 64 бит)

ЗАПУСК
  1. Распакуйте архив ЦЕЛИКОМ в любую папку (не запускайте из окна архива).
  2. Запустите HandPilot.exe. Значок появится в трее, при первом запуске откроется обучение.

Установка не нужна. Интернет не нужен: Python и все библиотеки лежат внутри папки runtime.
Ничего не пишется в реестр; настройки хранятся в %APPDATA%\HandPilot.

ЕСЛИ НЕ ЗАПУСКАЕТСЯ
  - Запустите HandPilot-debug.bat: он показывает сообщения об ошибках в окне.
  - Лог: %APPDATA%\HandPilot\handpilot.log, ошибки запуска: %APPDATA%\HandPilot\crash.log
  - Антивирус может ругаться на HandPilot.exe (маленький неподписанный лаунчер).
    Добавьте папку в исключения или запускайте через HandPilot-debug.bat.
  - Камеру должно быть можно открыть (Параметры - Конфиденциальность - Камера - разрешить
    классическим приложениям).
