# 🖐 HandPilot

**Управляйте компьютером жестами рук через обычную веб-камеру**

Курсор · клики · прокрутка · Alt+Tab · громкость · экранная клавиатура · русская дактильная азбука

> *English in brief:* HandPilot turns a plain webcam into a hands-free controller: pointer, clicks,
> scrolling, window switching, volume "knob", on-screen keyboard with word suggestions and Russian
> sign-language fingerspelling to text. Windows and Ubuntu (X11), Python 3.12, MediaPipe, PySide6.

## Возможности

- **Мышь:** курсор следует за рукой (режим «тачпад» или «указка»), клик, перетаскивание, правый клик, прокрутка.
- **Жесты-команды:** взмахи для Alt+Tab, обзора окон, назад/вперёд в браузере; «тумблер» для громкости; управление музыкой.
- **Экранная клавиатура** с подсказками слов, нажатие щипком.
- **Дактиль:** буквы русской дактильной азбуки превращаются в текст; пробел и удаление символа тоже жестами.
- **Обучение при первом запуске:** каждый шаг ждёт, пока вы действительно выполните жест.
- **Работает офлайн:** модели лежат в репозитории, облако не используется.

## Быстрый старт

### Windows: готовая сборка (рекомендуется)

Распакуйте архив **целиком** и запустите `HandPilot.exe`. Ни установка, ни интернет не нужны:
Python и все библиотеки лежат внутри. Сборка делается скриптом
[`tools/portable/build_portable.ps1`](tools/portable/build_portable.ps1) (≈100 МБ).

### Из исходников

```bat
scripts\setup.bat      :: один раз: создаёт .venv-app и ставит зависимости (нужен интернет)
scripts\run.bat        :: запуск без консоли, значок появится в трее
```

```bash
./scripts/setup.sh     # Ubuntu: системные библиотеки + .venv-app + зависимости
./scripts/run.sh
```

Ключи запуска: `--dry-run` (распознавать, но не трогать мышь и клавиатуру), `--video файл.avi`
(демо на видео), `--debug`.

### Ubuntu

Лучше всего работает сессия **«Ubuntu on Xorg»** (шестерёнка на экране входа). В Wayland синтетический
ввод разрешён только в окнах XWayland. Подробности и ограничения: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#платформы).

## Жесты

Показывайте руку ладонью к камере. 👍 с удержанием около секунды открывает меню режимов
(Мышь · Клавиатура · Дактиль · Пауза).

### Режим «Мышь»

| Жест | Действие |
|---|---|
| 🖐 движение ладонью | курсор |
| 👌 большой + указательный | клик · держать и вести — перетаскивание · два щипка — двойной клик |
| большой + средний | правый клик |
| ✊ кулак и движение | прокрутка («тянем страницу») по вертикали и горизонтали |
| ✌ «победа» + быстрый взмах | → / ← Alt+Tab и Alt+Shift+Tab · ↑ обзор окон · ↓ рабочий стол |
| 🤙 «шака» и наклон кисти | как поворот тумблера: вправо — громче, влево — тише |
| 🤘 «рок» + взмах | → / ← следующий / предыдущий трек · удержать ~0,8 с — пауза / воспроизведение |
| 🤟 три пальца + взмах | ← назад · → вперёд · ↑ обновить страницу |

Пока показана поза жеста-команды, курсор стоит на месте. Длина взмаха и шаг громкости настраиваются
в «Настройки → Жесты».

### Режим «Клавиатура»

| Жест | Действие |
|---|---|
| 🖐 наведение ладонью | выбор клавиши |
| 👌 щипок | нажатие · удержание на ⌫ и стрелках — автоповтор |

### Режим «Дактиль»

| Жест | Действие |
|---|---|
| буквы русской дактильной азбуки, цифры 1–5 | набор текста |
| 👍 | пробел (удержание — меню) |
| 👎 | удалить символ · пока жест удерживается, каждый кивок рукой вниз-вверх стирает ещё один |

**Горячие клавиши:** `Ctrl+Alt+H` пауза · `Ctrl+Alt+M` мышь · `Ctrl+Alt+K` клавиатура · `Ctrl+Alt+D` дактиль.
Физическая мышь продолжает работать параллельно.

## Настройки и данные

Настройки и выученные слова: `%APPDATA%\HandPilot\` (Linux: `~/.config/HandPilot/`). Логи там же:
`handpilot.log`, а при сбое запуска ещё и `crash.log`.

## Разработка

```text
handpilot/    приложение (core · tracking · engine · platform · text · ui · assets)
training/     обучение и анализ данных для дактиля
tests/        проверки жестов и прогон видео через весь конвейер
tools/        запись и разметка данных, сборка автономной версии
scripts/      установка и запуск из исходников
docs/         подробное описание устройства
```

```bash
python tests/test_shortcuts.py              # жесты-команды на синтетических данных (нужен только numpy)
python training/calibrate_poses.py          # пороги поз против размеченных данных
python training/train_fingerspelling.py     # обучение дактиля и экспорт модели
python tests/replay_eval.py                 # сквозной прогон записанных видео
```

Обучающие данные в репозиторий не входят, формат описан в [data/README.md](data/README.md).
Как устроен конвейер и почему выбран именно MediaPipe: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
